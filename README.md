congratulates itself, then still asks me to approve its own praise.

## How it works

`main.py` (Python stdlib only, no network) writes a single roast line to
`/output/entry.txt`. The output is deterministic — two runs produce
byte-identical files.

## The line

> My agent delegates to itself, congratulates itself, then asks me to approve its own praise.
